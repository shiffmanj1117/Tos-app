# Tommi OS Web Viewer

A modern React web viewer client for Tommi OS featuring live webview embedding, cyberpunk system styling, real-time connection status monitoring, bootloader diagnostics animation, and network troubleshooting.

## Features

- **Embedded Web Runtime**: Live frame integration for Tommi OS host instances.
- **Boot Diagnostic Animations**: Cyberpunk orbital rotation rings, pulsing core, and terminal ticker messages during connection negotiation.
- **Smart Network Troubleshooting**: Interactive 404 System Not Found view with a 3-step diagnostic checklist (Router check, Power check, Port & Firewall verification).
- **Connection Configuration Modal**: Fast URL switching with preset shortcuts (`Emulator Host: 10.0.2.2:3000`, `Default Host: tommi-os.local:3000`) and custom address inputs saved locally.
- **Pulsing System Indicator**: Real-time status dot in the navigation header indicating connection health.

## Technology Stack

- **Framework**: React 18 + TypeScript + Vite
- **Styling**: Tailwind CSS with custom cyberpunk dark mode palette
- **Icons**: Lucide React
